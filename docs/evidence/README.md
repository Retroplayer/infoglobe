# Reference photographs and schematic

Third-party reference material collected 2026-10-19 for identification and comparison. Rights remain with the original authors/photographers; no new license or permission to redistribute is asserted. These are photographs of other units, not our target unit.

`manifest.json` records original page/image URLs and SHA-256 hashes. File names describe the observation; they do not establish PCB compatibility. Associated adapters may have been replaced by prior owners.

- `purple-*`: purple dome, OL3000.2 underside label, powered display, and associated adapter.
- `ol3000lp-box.jpg`: retail packaging marked OL3000LP.
- `ol3000lb-*`: blue-product packaging and barcode.
- `orange-operating-display.jpg`: orange dome with warm-colored text; no readable underside label.
- `ol3000mc-*`: factory multicolor packaging, including its bottom/copyright panel.
- `multicolor-*`: red, blue, and green operating states in one listing with OL3000MC packaging.
- `morris-image001.jpg`: Morris's reference unit.
- `morris-image003.jpg`: Morris's add-on message-generator/interface schematic, **not the original factory schematic**.
- `morris-image005.jpg`: Morris's modified base photograph.
