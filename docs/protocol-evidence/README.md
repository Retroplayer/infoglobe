# Protocol reference data

Collected 2026-10-19 from public posts by kongmunist, DavidBerdik, and greenmikey. Rights remain with the authors; no new code license is asserted.

- `greenmikey-2018-captures.txt`: preserved successful raw Pastebin response.
- `captures.json`: five arrays extracted from that text plus the original-base array posted in issue 465; provenance and quality warnings included. The SHA-256 identifies the retained text. Array lengths were checked, but these noisy captures have not been decoded or replay-validated.
- `transition-comments.json`: four source gist comments with author, posting time, comment link, and text.

See ../protocol.md for interpretation. Durations are in microseconds. Unknown-protocol hash values from the original IR library are not Infoglobe command IDs.
